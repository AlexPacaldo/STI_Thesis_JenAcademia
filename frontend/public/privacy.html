Privacy Policy

Last updated: September 2026

JEN Academia ("we", "our", "the application") is an academic class-management platform built for a student thesis project. This policy explains what information the application handles when you use it.

1. Information we handle

The application stores account details (name, email, role), class schedules, attendance logs, and verification evidence such as screenshots and meeting recordings that you choose to upload. Recordings are stored in Google Drive and linked to a specific class attendance record.

2. Google Drive recordings

When a teacher records a class, the recording is uploaded to a Google Drive connected to this application. The file is stored with a shareable link (as is standard for Google Drive) and linked to the specific class attendance record. The link is only shared with the teacher, the student, and the administrators of that class so attendance can be verified and, where needed, reviewed later.

3. How data is used

Data is used only to run the application: verifying class attendance, completing class sessions, and allowing administrators to review submitted evidence.

4. Retention, access, and deletion

Class recordings are deleted automatically after a short retention period (7 days by default). Teachers and students can see the recordings for their own classes. Administrators can remove verification records, screenshots, and recordings at any time. To request deletion of your data, contact the administrator of your school.

5. Contact

For any privacy questions, contact the administrator of the institution that uses JEN Academia.
