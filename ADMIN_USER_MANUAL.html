Administrator

Creates teacher and student accounts, manages contracts and materials, monitors schedules, and reviews class evidence and reports.

Super administrator

Has the additional Create Admin option. An ordinary admin does not see this option. The protected super-admin account cannot be archived or restored through account management.

Using the manual: follow the steps for the task you need. Screens may adapt to the device size. Confirm the selected person, course, and class before saving a change.

Prepared from the application's administrator screens in November 2026. Features depend on the deployed version and the signed-in account's permissions.

01 · Getting started

Sign in & daily routine

Use the administrator account supplied by your school. Successful admin sign-in opens the Admin Dashboard.

Sign in

  1. Open the JEN Academia website and go to its sign-in page (/login).
  2. Enter your administrator email address and password.
  3. Submit the sign-in form. Check that the Admin Dashboard and administrator menu appear.
  4. If you forgot your password, use the password recovery link on the sign-in page and follow the instructions sent to your registered email.

A suggested daily workflow

WhenWhat to check
Start of the dayOpen Overview. Review today's timetable and items needing attention.
Before classesUse Calendar to review scheduled lessons and Requests to monitor reschedule activity.
When onboardingCreate the account, check the assigned course and teacher, and confirm that the setup invitation was delivered.
During administrationReview pending contract requests, package details, and expired contracts.
After classesOpen Verifications to review flagged records. Check Contract reviews for completed-contract feedback.

Finish your session

Use the account menu to sign out when you finish, especially on a shared device. If inactivity ends your session, sign in again before continuing your task.

Before submitting: recheck names, email addresses, assigned teachers, package counts, and dates. Read each confirmation dialog before confirming.

03 · Onboard a teacher

Create a teacher account

  1. Choose Create Teacher in the administrator menu.
  2. Optionally use Auto-fill From Resume. Select a PDF, DOCX, or TXT file up to 8 MB. Review every filled field before saving.
  3. Complete the teacher's First Name, Last Name, Email, Country, and Birthday.
  4. Select the teacher's courses. Complete the AI Matching Profile, including specialization, teaching style, ideal student pace, and experience years.
  5. Set the option indicating that the teacher does not teach children when applicable. Add useful teaching strengths and context in Teacher Bio / Notes.
  6. Choose Create Teacher. Review the name, email, and course count in the confirmation dialog, then confirm.
  7. Read the result message. A successful creation normally sends a setup invitation to the teacher's email. Check the invitation status in Account Management.
Resume assistance: auto-fill keeps existing text entries and combines matching selections with those already chosen. It can miss information. The administrator must check the result and complete missing details.

Update teacher course assignments

  1. Open Teacher Courses and search for the teacher or course.
  2. Select the courses the teacher should handle, then use the save action.
  3. Review and confirm the teacher and course selections.
Next step: ask the teacher to complete account setup and enter availability. Accurate courses, profile information, and availability support student matching.

04 · Onboard a learner

Create a student account

  1. Choose Create Student. Complete the learner's name, email, country, and birthday, then select Enroll in Course.
  2. Under Trial Class Assessment, complete the Level Evaluation. Score each displayed criterion from 1 to 5; the application computes the proficiency level.
  3. Complete the learner's Matching Criteria: learning goal, focus area, learning style, and pace. Use custom entries where the form provides them.
  4. Optionally set Preferred Class Time using the preferred days and time of day. Enter Trial Class Notes describing performance, strengths, and learning needs.
  5. Use Analyze with AI for matching assistance. Review the recommended teacher, fit information, and availability warnings. Select the intended Assigned Teacher.
  6. Under Class Package Information, select Number of Classes Availed (10, 15, or 20) and Class Duration (25 or 50 minutes).
  7. Choose Create Student. Review the confirmation summary, including course, computed level, teacher, and any schedule warnings, then confirm.
  8. Check the success message and invitation status. Confirm that the learner can receive the setup email.
Matching is assistance: review suggestions before saving. A teacher recommendation or preferred time does not book a class. Check availability and complete the normal booking process separately.
If analysis is unavailable: keep the assessment and matching information accurate, select an appropriate teacher manually, and follow any validation message shown by the form.

05 · Account management

Account access & invitations

Find an account and correct its email

  1. Open Account Management. Search by name, email, or role and locate the user under Active Students or Active Teachers.
  2. Open the user's account details. Check their setup progress, invitation status, and invitation expiry.
  3. To correct the sign-in address, enter the new email and choose Save email. Read the result message before closing the dialog.

For an account still awaiting setup, changing the email replaces the unused invitation and sends a fresh link. For a completed account, tell the user to use the new address for future sign-ins and password resets.

Help a user complete setup

  • For unfinished setup, choose Resend Invite to send a fresh invitation.
  • Use Copy Fresh Link when you need to share a new setup link privately. If automatic copying fails, use the manual-copy dialog.
  • Ask the user to use the newest link and check their spam folder. Once setup is completed, invitation controls are no longer shown.
  • If the account was created but email delivery failed, recover the invitation from account management instead of creating the account again.

Archive or restore an account

  1. For an active student or teacher, choose Archive. Confirm the correct user in the dialog.
  2. To reactivate a user, find them in the archived users list and choose Restore, then confirm.
  3. Also check Archived by the Dormancy Rule for accounts closed automatically after inactivity. The panel provides a restore action.
Effect on access: archived users cannot continue normal account access. Restore the account when access should resume. The protected super-admin account is excluded from these actions.

06 · Super-admin task

Create an admin account

Only a signed-in super administrator can open Create Admin. If the menu item is absent, ask the school's super administrator to create the account.

  1. Choose Create Admin from the administrator menu.
  2. Enter the new administrator's First Name, Last Name, Email, Country, and Birthday.
  3. Enter a strong password of at least 8 characters. This is the password the new administrator will use to sign in.
  4. Review the person's details and submit the form using its create action.
  5. Check the result message. Share the sign-in address and credentials privately with the intended administrator.
  6. Ask the new administrator to sign in and confirm that the Admin Dashboard opens.
Account setup differs by role: student and teacher creation uses setup invitations. The Create Admin form asks the super administrator to set the initial password directly.

Keep administration accountable

Use individual accounts

Give each administrator their own sign-in. Keep passwords and setup links private.

Check the intended role

Use the correct creation form. A learner or teacher should be created through their corresponding menu option.

07 · Scheduling oversight

Calendars & reschedule requests

Review the school calendar

  1. Open Calendar from the administrator menu.
  2. Move to the date or month you need and inspect the scheduled classes.
  3. Select a class to review its participants, schedule, and current status.
  4. Compare the class details with the relevant student's contract and assigned teacher before following up on a conflict.

Monitor a reschedule request

  1. Open Requests and use the status filters to find the request.
  2. Check the class, teacher, student, current schedule, requested schedule, and reason.
  3. Review whether it is pending, approved, or declined. If declined, read the displayed decline reason.
  4. For pending items, follow up with the responsible participant. After a decision, check the class schedule and request status.
Decision ownership: this admin screen monitors participant reschedule requests. It does not provide admin approval or rejection buttons for them. Contract requests have separate approval controls under Contracts.

Remove a request record

The Remove request action opens a confirmation. Use it only when the request record should be removed, and check the selected item before confirming. Removing a request is not a reschedule approval.

Compare the displayed times: check the date and time zone when discussing a schedule with teachers or learners in another country.

08 · Student packages

Manage class contracts

Use Contracts to review student packages, remaining classes, and expiry information.

  1. Open Contracts and locate the student's package. Search by student, email, course, teacher, or status; adjust the filters as needed.
  2. Review the current totals, classes used, classes remaining, assigned teacher, package status, and expiry badge.
  3. Change the required fields in the package card. Use the table below as a reference.
  4. Use the save action and review the confirmation summary. Confirm only after checking the student, course, teacher, total classes, and usage.
  5. Check the saved record and remaining balance after the operation succeeds.
FieldWhat to check
CourseSelect the correct course. Use Keep current when appropriate.
TeacherSelect an eligible teacher for the course. Check Teacher Courses if the expected teacher is missing.
DurationChoose 25 or 50 minutes for the package.
Total classesEnter the agreed package total.
Classes usedEnter the correct usage count; it must not exceed the total.
StatusChoose Active, Expired, or Cancelled to reflect the package's actual state.
Balance example: 15 total classes with 6 used leaves 9 classes. Changing totals or usage changes the learner's remaining balance. Check the class history before correcting a count.

09 · Contract decisions

Contract requests & extensions

Review a pending contract request

  1. Open Contracts and find the contract requests area.
  2. Use the search and status filters to locate the student. Read the request type, course, requested classes, reason, and any displayed package details.
  3. Expand earlier versions when revision history is available. Make your decision using the latest request.
  4. Choose Approve request or Decline. Review the student, course, and action in the confirmation dialog, then confirm.
  5. Check the resolved status. After approval, review the resulting package in the contracts area.

Approve an extension

  1. For an extension request, inspect the student's current package status and expiry.
  2. Choose Approve extension to open the extension dialog.
  3. Set the New end date. Read the dialog's instructions and confirm the extension.
  4. Verify the request outcome and the package's updated expiry information.

An extension changes the existing contract's end date. It keeps the package and class usage intact. Payment is handled outside the system; recording an extension does not charge the learner.

Clear resolved requests from the active list

For an approved or declined request, Remove from list archives the resolved record. Review the confirmation before proceeding; the record is archived rather than deleted.

Keep request types distinct: a new-contract request concerns a class package. An extension request concerns the package expiry. Participant date or time changes appear under Requests.

10 · Attendance & evidence

Verify class records

  1. Open Verifications. Search by class, teacher, student, or date and use the status filters to locate records requiring attention.
  2. Confirm the class and participants. Read any missing-evidence notices and review reasons.
  3. Expand Attendance and notes. Compare when the teacher started, the student joined, and the teacher ended the class. Read the class summary and teacher's review request.
  4. Open Start photo, Watch recording, or End photo when available. Check that the evidence supports the class record.
  5. For a record waiting for admin review, choose Approve verified if the evidence supports completion, or Mark incomplete if it does not.
  6. Read the confirmation and check the class, teacher, student, and schedule before confirming. Verify the updated status.
Record stateAdministrator response
PendingCheck which class steps or evidence are still outstanding.
Waiting for admin reviewInspect the reasons and supporting evidence, then approve or mark incomplete.
VerifiedThe verification is finalized. Review it if a class-record question arises.
IncompleteThe record is finalized as incomplete. Read its evidence and notes when following up.
Evidence cleanup: Remove record and Clear Final Records remove verification logs and their uploaded proof files. Bulk clearing applies only to verified and incomplete records; pending and admin-review records stay. Review the confirmation carefully and retain any needed evidence before cleanup.

11 · Library management

Books & teacher access

Add a book

  1. Open Books / Lessons and choose Add Book.
  2. Enter the title and course. Add an optional description and cover image. The cover picker accepts JPG, PNG, and WEBP.
  3. Under Distribute to teachers, select the teachers who should receive the book. You can also leave distribution empty and assign it later.
  4. Save the book and check that its title, course, and teacher distribution are correct.

Change details or distribution

  • Search by title, course, or teacher to find the book.
  • Use Edit Book to update its editable details and cover.
  • Use the distribution control to change which eligible teachers receive it, then save.
  • When changing the course while creating a book, reselect teachers for the new course; earlier teacher selections are cleared.

Archive or restore a book

Use Archive and confirm when the book should leave the active library. Its lessons and student progress are kept. To bring it back, switch to the archived view and choose Restore, then confirm.

Who can see the material? Administrators maintain the shared library. Teachers see books distributed to them. Student access follows the assigned teacher and course. Removing distribution removes the affected teacher's access.
Retiring material: books use archive and restore controls. Open a book to manage its individual lessons and check learner progress.

12 · Learning materials

Lessons & student progress

Upload a lesson

  1. Open Books / Lessons and enter the intended book's content page.
  2. Choose + Upload Lesson.
  3. Enter the lesson title and complete the other fields shown in the upload dialog.
  4. Select the learning file. The picker accepts PDF, DOC, DOCX, and TXT. Add any additional notes.
  5. Choose Upload and wait for the success result.
  6. Open the new lesson from the list and check its title, notes, and uploaded file.

Check book content and cover

Select a lesson to inspect its uploaded material. Use the book's cover-change control when a new cover is needed, then save the image and confirm its appearance.

Review learner progress

  1. Open the book's Students Progress area.
  2. Locate the learner and review the lesson-completion information.
  3. Use the progress record to identify lessons needing follow-up with the assigned teacher.

Delete an individual lesson

Choose the lesson's delete control. Read the Delete this lesson? dialog and verify the selected lesson before choosing Delete lesson. Use the cancel action if you selected the wrong item.

Check the scope: archiving a book preserves its lessons and progress. Deleting an individual lesson is a separate action; review the confirmation before removing learning material.

13 · Evaluation & feedback

Contract review reports

Use Contract reviews to read the teacher's evaluation of a learner and the learner's rating of their teacher after a contract is completed.

  1. Choose Contract reviews from the administrator menu.
  2. Search by student, teacher, course, level, or status. Use the filters to narrow the reports.
  3. Review the report summary and submission states. A Pending label means that side's review has not yet been submitted.
  4. Choose View report for the intended student and contract.
  5. Read the teacher evaluation, which uses five proficiency criteria, and the student rating, which uses five teaching criteria. Review the submitted scores and feedback.
  6. Close the report after reviewing it. Follow up with the relevant person if a submission is still pending or the feedback needs attention.
When a report appears: a report opens when every class in a contract has been completed. A report may still show pending feedback until the teacher or learner submits their review.

Use the right record for your question

QuestionWhere to look
Was the class supported by attendance and proof?Verifications
How many classes remain in the package?Contracts
Which lessons has the learner completed?The book's Students Progress area
What did the teacher and learner report after the contract?Contract reviews → View report
Read both sides: use teacher evaluations to understand learning progress and student feedback to understand the teaching experience.

14 · Help & reference

Common issues & glossary

Create Admin is missingThis option requires a super-admin account. Ask the school's super administrator to create the account.
Setup email did not arriveCheck the address and spam folder. Use Resend Invite or Copy Fresh Link for unfinished accounts. Report a delivery warning to system support.

Words used in the platform

Contract / package: the learner's class allocation, usage, duration, status, and expiry. Verification: attendance and evidence used to confirm a class. Distribution: a teacher's access to a book. Archive: moving a supported record out of active use, with restore available where shown. Setup invitation: the link a new student or teacher uses to finish account setup.

When you need help

Give system support the affected screen, record or class, approximate time, exact error message, and steps that led to it. Share screenshots through the school's approved support channel and keep passwords and setup links private.
