Which guide should I use?

Visitors can explore services and contact the school. Students manage their own learning. Teachers manage assigned learners and classes. Administrators manage school operations. Super administrators have the same operational guide plus their additional Create Admin procedure.

Each role manual is self-contained. There is no need to read another role’s guide to complete your ordinary tasks.

About the pictures Interface pictures use the current frontend with fictional sample data. Workflow illustrations explain task sequences. No live account records are shown.
